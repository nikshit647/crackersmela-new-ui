=============================================================================
  Tips for Best Results
=============================================================================

1. In Midjourney, append "--ar 16:9" for widescreen or "--ar 9:16" for
   mobile-first layouts.

2. Add "--v 6.0" for the latest Midjourney model with better text rendering.

3. Use "--style raw" to get more literal interpretations without
   Midjourney's default stylization.

4. For DALL-E, paste the prompt directly — DALL-E 3 handles long,
   descriptive prompts well.

5. To refine results, add these keywords:
   - "flat design" for cleaner, simpler layouts
   - "isometric view" for 3D-perspective mockups
   - "wireframe" for structural layouts before adding color
   - "high fidelity" for production-ready mockups

6. For consistent brand colors across multiple generations, include the
   hex codes in each prompt.
